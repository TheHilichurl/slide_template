## ⌨️ HƯỚNG DẪN ĐIỀU KHIỂN & PHÍM TẮT TRÌNH CHIẾU

- **`Phím Mũi tên Phải (→)` hoặc `Phím Cách (Space)` hoặc `PageDown`:** Chuyển sang Slide tiếp theo.
- **`Phím Mũi tên Trái (←)` hoặc `PageUp`:** Quay lại Slide trước đó.
- **`Phím F`:** Bật / Tắt chế độ toàn màn hình (Fullscreen Presentation).
- **Thanh Tab & Menu Thả:** Nhấp chuột trực tiếp vào thanh điều hướng 20 Tab ở phía trên để chuyển nhanh tới phong cách mong muốn.
- **Nút "Mở File Độc Lập":** Mở trực tiếp file HTML đơn lẻ để nhúng hoặc chỉnh sửa mã nguồn độc lập.

## 📐 TIÊU CHUẨN THIẾT KẾ KỸ THUẬT

1. **Cỡ chữ đạt chuẩn trình chiếu:** Toàn bộ nội dung chính (body text) có kích thước $\ge 25\text{px}$, line-height 1.55, đảm bảo người tham dự ở khoảng cách xa vẫn đọc rõ nét.
2. **Khung nhìn tỉ lệ vàng 16:9:** Thiết kế trên canvas gốc `1920x1080px`, tự động co giãn (`updateStageScale`) theo thời gian thực khi thay đổi kích thước cửa sổ.
3. **100% Tư liệu hình ảnh Quốc phòng Việt Nam:** Sử dụng ảnh chính quy về Quân chủng Hải quân, Phòng không - Không quân, Lục quân, Tác chiến điện tử, Đền Hùng và Lăng Bác.
4. **Không phụ thuộc thư viện nặng:** Xây dựng thuần HTML5, Vanilla CSS3 (Custom Properties Tokens) và JavaScript nhẹ, nạp tức thì trong vòng dưới 1 giây.
